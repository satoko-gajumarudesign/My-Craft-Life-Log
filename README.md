# Relaxed Magazine - My Blog Theme

## プロジェクトの概要
「30代向けのリラックスしながら読める写真多めの雑誌風ブログ」をコンセプトに、ゼロから独自に設計・開発したWordPressオリジナルテーマです。
読者が日常の喧騒から離れ、ゆったりとした時間を過ごせるようなUI/UXを目指し、パフォーマンスと保守性の両立にこだわって実装しています。

## ターゲットとコンセプト
*   **ターゲット:** 30代の読者。日々の生活に少しの彩りと癒やしを求めている方。
*   **コンセプト:** 写真の魅力を最大限に引き出す、雑誌のページをめくるような心地よい体験の提供。

## デザインとUI/UXのこだわり

### 1. 呼吸空間を意識したレイアウトと色彩設計
余白の取り方や配色のバランスには、日本的な空間芸術や生け花の配置美から着想を得た「間」の概念を取り入れています。
*   **Base Color (`#f3f3f3`):** 真っ白ではない温かみのあるオフホワイトを採用し、長時間の読書でも目が疲れにくい設計。
*   **Accent Color (`#D4A373`):** 上品で落ち着いたキャメル系カラーをあしらい、リラックスした雰囲気を演出。

### 2. 回遊性を高める5つのカテゴリー設計
読者が迷わず、直感的に興味のある記事へアクセスできるようナビゲーションを最適化しています。
*   `CODE`: 日々の学習や技術的なアウトプット
*   `TABLE`: 日々利用しているミールキットの紹介
*   `BUDDY`: 愛犬との穏やかな日常風景など、サイトに温かみをもたらすコンテンツ
*   `ITEMS`: お気に入りのアイテム紹介
*   `NEWS`: サイトからのお知らせ（カスタム投稿タイプで分離し、定型文を制御）

## 技術スタックとアーキテクチャ

本テーマは、実務レベルでの運用と将来的な拡張を見据えたアーキテクチャを採用しています。

### CSS設計: FLOCSS + BEM命名規則
コードの可読性と保守性を担保するため、FLOCSS（Foundation, Layout, Object, Project, Utility）に基づいたディレクトリ構成とし、クラス名はBEMの厳格な命名規則に則って記述しています。
*   特定のコンポーネントが他のスタイルに干渉しない堅牢な設計。

### セキュリティ対策の徹底
WordPressの脆弱性を防ぐため、以下のベストプラクティスを実装しています。
*   出力時の適切なエスケープ処理（`esc_html()`, `esc_url()`, `wp_kses_post()` の適材適所での使い分け）。

### SEO・パフォーマンスの最適化
写真中心のメディアであるからこそ、表示速度の低下を防ぐ施策を講じています。
*   **画像最適化:** WebPフォーマットの採用、ネイティブの `loading="lazy"` による遅延読み込み。
*   **アクセシビリティ:** 画像の `alt` 属性の適切な設定、セマンティックなHTML（見出しレベルの正しい階層化）によるクローラビリティの向上。

##  動作環境
*   WordPress: 6.x 以上推奨
*   PHP: 7.4 以上（8.x 推奨）
